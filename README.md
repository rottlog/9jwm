# [9jwm]

A Minimal WM.

## Usage

Drag Win = `Super Key` + `Left Mouse Click`

Delete Win = `Super Key` + `Middle Mouse Click`

Resize Win = `Super Key` + `Right Mouse Click`


Open Terminal = `Super Key` + `Return`

Open Dmenu = `Super Key` + `D`

Open Browser = `Super Key` + `B`

## Building

Dependencies:

- xcb
- xcb-cursor
- xcb-keysyms

Build by running:

    make all
    sudo make install
